What it is

IP cameras with video analytics (line crossing, intrusion, object detection, loitering and many more) report what they see as ONVIF event metadata, a stream of XML next to the video. Event Metadata Monitor connects to that stream over RTSP and shows each event the moment it arrives, as one readable line: the time, the feature, whether it started or ended (True / False), the rule that fired, and the details you choose, such as the object ID, the action (Enter / Exit), the speed or the count.

No video is decoded and nothing is installed on the camera: it is a light, read-only view of what the camera is telling your video system.

Setting up analytics

Walk the scene and see at once which rules fire, with which state and object, instead of guessing from a recording later.

Integration and testing

Read the exact metadata a video management system or your own software will receive; copy any event's XML with a double-click.

Long runs

Leave it running for hours or days: counts and rates per feature, packet loss and memory charts, and logs saved to disk if you want them.

  • Live event log with a colour per timestamp, so events of the same moment group together.
  • Filters: features (right-click one to show only it), True / False state, rule.
  • Pause (Space) stops printing so you can read; a banner marks the pause and how many events it skipped.
  • Metadata on a double-click: a timestamp copies that event's XML; a feature name shows it, colour-coded, with a picture of it on the clipboard.
  • Your fields: choose which SimpleItem values follow each event (ObjectId, Action, Speed, Count, or add your own).
  • Event statistics: True / False / total per feature, Enter / Exit counts, average rates, the last state and the time since it.
  • Health charts: RTP packet loss over the last minutes or the whole session, and the app's own memory use.
  • Saving: event logs and raw metadata per camera, each switched on only if you want it.
  • Any ONVIF camera: the metadata path is filled in for Avigilon, Axis, Bosch, Dahua, Hanwha Vision, Hikvision and Uniview (and can be changed per maker in Settings), and the list is not a limit: any camera that streams ONVIF metadata over RTSP works with its own path.
  • Any analytics app: every event is shown under its own name, from whichever app or rule engine sent it; nothing to set up.
  • Steady: reconnects by itself when the stream drops; cameras, passwords and channels 1-8 are remembered.
  • Portable and up to date: no installer; Update now installs a new version in place.

Getting started

  1. Enter the camera's IP address, user name and password. Choose its Maker to fill in the path of its metadata stream. Not in the list? Choose Custom and enter the path from the camera's ONVIF settings or manual (ONVIF Device Manager shows it too). Click Log In.
  2. Click Conn next to the camera. Events appear as the camera sends them.
  3. Use Features, State and Rule to narrow the log, and Show event statistics for the counts.

How to use

The basics, a few seconds each: the same as Help › Tutorial in the app (simulated camera data).

Download

Windows 10 / 11, 64-bit. One zip with everything in it (GStreamer, the streaming library, is included): nothing else to install.

Download
From the latest release on GitHub
  • Unzip it (right-click > Extract All) anywhere you can write to, not Program Files, and start EventMetadataMonitor.exe in the EventMetadataMonitor folder.
  • Windows may say "Windows protected your PC" for a new app: click More info > Run anyway.
  • The app is portable: your cameras and settings (cameras.json), logs and saved data stay in its folder.

Updating

The app tells you when a new version is out: by itself once a day (Settings > General > Check for updates automatically, on unless you turn it off), or at once with Help > Check for updates. Click Update now: it downloads the new version, checks it, restarts and reconnects, and keeps your cameras, settings and saved data. If the app's folder cannot be written to, unzip the new version over it instead.

Network blocks this website? The app then checks on github.com instead, and the downloads are on the GitHub releases page.
